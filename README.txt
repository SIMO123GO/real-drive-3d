REAL DRIVE 3D — نسخة السيارات والمدينة الحقيقية
==================================================

كل ملفات GLB التي رفعتها (15 سيارة + مدينة) موضوعة مسبقًا داخل مجلد models/
داخل هذا الأرشيف، ومربوطة تلقائيًا بالكود. لا تحتاج نقل أي شيء يدويًا.

السيارات ذات النموذج الحقيقي (علامة ✦ في المعرض، ومفتوحة دائمًا بدون انتظار مهام):

- BMW M3 E30

- Lamborghini Terzo Millennio

باقي السيارات (حوالي 28) تبقى بالشكل الإجرائي المبني بالكود، وتُفتح تباعًا بإكمال المهام كما كان.

المدينة:
--------
تم تحميل city_map_free.glb كحيّ تفصيلي واقعي في "وسط المدينة"، فوق قاعدة مسطحة لضمان عدم وجود
فراغات. باقي المدينة (الطرق، المباني الإجرائية، طريق السرعة، منطقة السباق، ورشة التعديل، المعرض)
بقيت كما هي لضمان اشتغال الاصطدامات وحدود الخريطة والمهام بشكل مضمون دون كسر اللعبة، لأنه لا يمكن
اختبار المدينة الجاهزة بصريًا هنا قبل تسليمها لك. إن أردت أن تصبح المدينة الجاهزة هي كامل الخريطة
بدل أن تكون معلمًا مركزيًا فقط، أخبرني بعد تجربتها وسأعيد بناء الخريطة بالكامل حولها.

ملاحظات تقنية:
---------------
- حجم مجلد models كبير (بعض الملفات تجاوزت 70-110 ميجا)، فأول تحميل قد يستغرق وقتًا حسب سرعة إنترنتك،
  خصوصًا bmw_m4csl.glb وfree_bmw_m3_e30.glb وmercedes_gt63_amg.glb وaudi_rs5.glb.
- تدوير العجلات على السيارات الحقيقية يعمل تلقائيًا عبر اكتشاف أسماء أجزاء مثل wheel/tire/rim داخل
  كل ملف. في بعض الملفات قد لا تُسمّى الأجزاء بهذه الطريقة فلا تدور، وهذا يُصلح لاحقًا يدويًا لكل ملف
  عند الحاجة.
- إن ظهرت أي سيارة مقلوبة الاتجاه (تسير للخلف بصريًا)، اضغط زر O أثناء القيادة لقلبها، وأخبرني أي سيارة
  بالتحديد لأجعل القلب افتراضيًا لها في الكود مباشرة.
- تلوين الطلاء يعمل تلقائيًا إن كانت خامة الطلاء داخل الملف باسم يحتوي "paint" أو "body". إن لم يتغير
  لون سيارة معينة عند تحريك شريط اللون، أخبرني باسمها وأفحص أسماء الخامات داخل ملفها وأصلح الكود.

التشغيل:
--------
1. فك ضغط الأرشيف كاملاً (يشمل مجلد models).
2. شغّل سيرفر محلي من داخل المجلد: python -m http.server 8000
3. افتح المتصفح على http://localhost:8000
4. WASD/الأسهم للقيادة، Space فرامل يد، C تبديل الكاميرا، R إعادة ضبط السيارة، O قلب اتجاه سيارة GLB.
